# 画像生成用特徴量リスト：女性40人 ver2

[設計書_ver2.md](設計書_ver2.md) の形態24項目・印象10項目・8タイプに対応する、再生成用の確定計画リスト。

## 読み方と共通条件

- 全員、**整った容姿と自然な顔立ちを持つ27歳の架空の成人日本人**。特徴値の大小は容姿の良し悪しを示さない。
- 正面・閉口・無表情、灰色背景、同じ柔らかい正面光、写実的な美容写真。髪・服・肌の撮影品質を揃える。詳細は設計書2節。
- `shape_features` は各24項目を省略せず記載した生成目標。共通尺度 `0.00〜1.00` のうち自然な範囲 `0.15〜0.85` を使用する。実測値・承認済み評点ではない。
- `prompt` は共通条件と24項目の形態表現を含む完成プロンプト。そのまま1レコードにつき1人の生成に使用する。3区分の翻訳ルールは設計書4.3節。
- `tags` は設計書6.3節による互換用10値で、小数第2位へ丸めてある。画像レビュー後の形態値が変われば必ず再計算する。
- `label` と `generation_group` は制作管理用。生成プロンプトへの追記、診断カード上の表示、診断の直接判定には使わない。
- 全件 `review_status="planned"`、`asset_version="v2-planned"`。`image` は再生成後の配置予定先で、同名の既存画像が本特徴量に対応するという意味ではない。
- 今回の作成範囲は本計画。既存の `data/` と `assets/` は更新しない。画像生成・レビュー後に両者を同時更新する。
