# AI顔タイプ診断 サービス仕様書

## コンセプト

AI生成された人物画像を2択で選ばせ続け、
ユーザーの「顔の好み傾向」を分析する診断サイト。

例：

- つり目好き
- アヒル口好き
- クール系好き
- アンニュイ系好き
- 中顔面短め好き

などを診断する。

最終的に、

「あなたが最も惹かれる顔」

を表示する。

---

# サービスの方向性

これは「AI分析ツール」ではなく、
「SNSでシェアしたくなる診断コンテンツ」。

重要なのは分析精度ではなく、

- 当たってる感
- 解像度高い言語化
- シェアしたくなる結果

である。

---

# UXフロー

## 1. 性別選択

最初に：

- 男性を診断
- 女性を診断

を選択。

恋愛対象を前提とする。

---

## 2. 顔を2択表示

ユーザーに：

「どっちがタイプ？」

を選ばせ続ける。

操作はスマホ最適化。

- 左右タップ
- スワイプ
- 次へ高速遷移

を重視。

---

## 3. 好み特徴を蓄積

各画像には事前に特徴タグを持たせる。

例：

```json
{
  "cool": 0.9,
  "cute": 0.2,
  "tsurime": 0.8,
  "adult": 0.7,
  "idol": 0.1,
  "mysterious": 0.6
}

ユーザーが画像Aを選んだら、
その画像の特徴量を preference に加算。

preference.cool += 0.9
preference.tsurime += 0.8
