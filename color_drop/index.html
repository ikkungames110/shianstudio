Timing Game

色あわせドロップ

落ちてくるブロックが指定色と一致し、判定枠に入った瞬間を狙ってタップします。

Score0
Combo0
Time30

Target Color

赤

指定色と同じブロックだけを、黄色い判定枠の中で止めると得点です。違う色を押すとコンボが切れます。

スタートで開始

遊び方

  • 指定された色を確認します。
  • 同じ色のブロックが判定枠に入ったら押します。
  • 連続成功でコンボ点が増えます。

スペースキーでも判定できます。30秒でどこまで伸ばせるかを試す短時間ゲームです。

制作メモ

見てから押す緊張感

同じ色でも位置がずれていると得点になりません。色の一致とタイミングを同時に見る設計にしています。

スマートフォン向け

大きな判定ボタンと単純なルールで、片手でも遊びやすいテンポにしています。
